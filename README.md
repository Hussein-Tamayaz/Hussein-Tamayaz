## About

I run engineering at **[Tamayaz](https://tamayaz.io)**, where I build SaaS products and AI agents that automate the boring parts of running a business. By day I'm shipping a full-stack invoicing, CRM, and visual workflow platform. By night I'm wiring Claude into Telegram bots, Salesforce orgs, and ops dashboards so teams can talk to their data instead of clicking through it.

## What I'm building

| Product | What it does | Stack |
|---|---|---|
| **Tamayaz** | Invoicing, CRM, and a visual automation engine for service businesses. Live at [app.tamayaz.io](https://app.tamayaz.io). | React 19, Tailwind 4, Express, Postgres, BullMQ, Expo |
| **Yara** | A Telegram-native Claude agent that drives a dev server, generates content, books reminders, and runs job flows on the team's behalf. | Node, Telegram Bot API, BullMQ, OpenAI, Vertex |
| **Client work** | Multi-tenant security ops, AI coaching platforms, procurement and eCommerce on Salesforce, flight ops sync. Greenfield rebuilds and zero-to-one SaaS scaffolds. | Next.js, tRPC, Drizzle, Cloud Run, Puppeteer, MCP |
